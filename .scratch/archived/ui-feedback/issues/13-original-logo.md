# Original logo replaces a Font Awesome Pro icon

Status: resolved
Type: task

## Why

The dice logo used since the first commit (`392d73a`), and reused for the favicon, the PWA icons, the hero, the footer and the coins, turned out to be Font Awesome's **dice-d10 (Classic Solid)**: "Using this requires Font Awesome Pro" (fontawesome.com/icons/dice-d10). The user found it re-hosted, with no licence, on hexmos.com freedevtools. It can't be used without a Pro licence. The user chose an original drawing (2026-11-07).

## Answer

- **New mark:** an original **d20**: a pointy-top hexagon silhouette, a front triangle and four surrounding facets, separated by small gaps.
  - It's generated by `scripts/logo-d20.py` (the geometry is in the script; `python3 scripts/logo-d20.py 28` prints the path in a 1024 box). The design is deliberately different from the old d10 kite.
  - It's own work, so no credit is needed.
- **Replaced in:**
  - the nav bar, the landing hero, the site footer and `public/favicon.svg`;
  - the three coin SVGs;
  - `favicon.ico` (16, 32 and 48 px) and the 8 PWA icons, regenerated.
- **Checked:**
  - The old path no longer appears anywhere in `src/` or `public/`.
  - Readable at 220, 32 and 16 px. In the browser, the nav, hero backdrop and footer show the new mark, with no console error.
  - Suite and build green.
- **Note:** the old icon is still in git history (first commit). Rewriting published history isn't worth it for an icon; it's gone from the app.
